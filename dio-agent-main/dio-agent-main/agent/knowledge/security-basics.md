# Fundamentos de Segurança da Informação
## Princípios de Segurança
### Disponibilidade

A disponibilidade garante que os sistemas e dados estejam acessíveis e utilizáveis quando necessário. Isso envolve a implementação de medidas para prevenir interrupções, como redundância, backups e planos de recuperação de desastres.

## Boas Praticas

### Confidencialidade

A confidencialidade assegura que informações sensíveis sejam acessadas apenas por pessoas autorizadas. Isso pode ser alcançado através de criptografia, controle de acesso e políticas de segurança rigorosas.

### Integridade

A integridade garante que os dados não sejam alterados ou corrompidos de forma não autorizada. Isso pode ser mantido através de mecanismos de verificação, como somas de verificação, assinaturas digitais e auditorias regulares.
